# 🧮 Calculadora CLI

Calculadora de linha de comando desenvolvida em Node.js para executar operações matemáticas básicas.

---

## 📌 Sobre

Projeto focado em lógica de programação, permitindo realizar cálculos diretamente pelo terminal com validação de entrada e tratamento de erros.

---

## ✨ Funcionalidades

* Soma, subtração, multiplicação e divisão
* Potência, módulo e porcentagem
* Validação de entrada
* Tratamento de erros (ex: divisão por zero)

---

## ⚙️ Requisitos

* Node.js instalado

---

## ▶️ Como executar

Clone o repositório:

```bash id="x701cv"
git clone https://github.com/KaweM/calculadora-cli.git
cd calculadora-cli
```

Execute o projeto:

```bash id="l8ygmw"
npm start
```

---

## 🧪 Exemplo de uso

```text id="3y9y6h"
Digite o primeiro número: 10
Digite o segundo número: 5
Operação: /

Resultado: 2
```

O usuário deve informar os números e escolher a operação desejada.
